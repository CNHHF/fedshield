# FedShield 同学部署说明

## 使用分享压缩包

1. 安装 64 位 Python 3.12（或 3.13），安装时选择加入 PATH。解压整个压缩包，不要在压缩软件内直接运行。
2. 首次双击根目录 `setup.bat`。程序创建独立 `.venv`，从 PyPI 安装依赖。首次需要联网；安装失败会停止，不会忽略错误继续启动。
3. 双击 `start.bat`，保留控制台窗口。页面自动打开，默认地址 `http://127.0.0.1:5000/`；端口占用时会选择后续空闲端口并显示实际地址。
4. 登录：`risk.officer`，口令 `FedShield@2026`，MFA `123456`。这些是本地演示账号，不用于公网部署。
5. 停止：在服务窗口按 Ctrl+C。下次直接双击 `start.bat`。

分享包自带前端编译结果，运行不需要 Node.js。Python 依赖未随包内置，不是完全离线的免安装程序。NumPy 固定为与当前 scikit-learn 1.9.1兼容的2.5.3，避免旧NumPy导致模型接口异常。

## 数据和现有界面

分享包包含可再分发的 UCI Online Retail、ECB、World Bank 和 OFAC 数据快照及来源说明。工作台可用真实零售订单进行分级保护、规则检查、本机联邦与审计演示；金融数据页可查看零售、汇率、年度统计和名单候选。23张表的结构保留，数据数量按分享包实有内容显示。

CTU-BERKA银行研究数据和ULB信用卡数据的现有来源记录未明确再分发许可，因此不包含它们的流水、账户、模型或预测文件。银行/信用卡相关标签页可能无记录，信用卡模型也不会显示本机原研究指标。需要补全时，应先核对来源许可，再按照 `FINANCIAL_DATABASE.md` 在自己的电脑下载、建库和训练。不要把分享包的数量写成原研究库的1,367,027条。

用户、预算、支付通道等部分业务界面会在新环境初始化演示记录。这些和真实公开零售数据分开；首次启动生成新业务库、会话签名密钥和本机保护密钥，不包含发送者的会话、材料或历史审批。

## AI功能

本地风控问答可在无大模型密钥时使用；业务材料智能配置等依赖DeepSeek服务的功能，需要接收人自行设置 `DEEPSEEK_API_KEY` 环境变量，然后重启系统。可选 `DEEPSEEK_MODEL`，默认 `deepseek-chat`。也可参照 `docs/BUSINESS_CONFIGURATION.md` 的本地配置方式。

包中不附带发送者的API密钥，也不会自动把新密钥提交GitHub。使用远程模型前，应确认输入材料是否适合发送给该服务。规则方案仍需人工确认和启用。

## 从GitHub源码启动

源码仓库不含编译文件、大型数据库或私钥。准备Python 3.12/3.13和Node.js 20+后：

```powershell
python tools/setup_peer.py
.venv\Scripts\python.exe tools/launch_peer.py
```

该方式自动编译前端并下载构建UCI主流程数据。若要与分享包一样拥有金融参考库，可下载同版本GitHub Release中的同学演示包。完整研究库的数据重建见 `docs/FINANCIAL_DATABASE.md`。

## 排查

- 缺少Python：安装后重新打开终端，运行 `py -3.12 --version`。
- 依赖安装失败：检查网络和Python版本；不要跳过依赖错误。
- 页面空白：确认 `frontend/dist/index.html` 存在；源码版运行 `npm ci` 和 `npm run build`。
- 金融银行或信用卡无数据：见上面的分享数据范围，不是原始本机库丢失。
- AI材料分析提示未配置：由接收人设置自己的API密钥；本地问答和其他主流程仍可使用。

此包是本机演示部署，默认只监听127.0.0.1，不执行真实资金支付。
